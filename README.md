# 세력 매집 탐지기 (Volume Accumulation Tracker)

거래량 패턴으로 세력의 **매집 흔적**을 찾아내는 웹 시스템입니다.
종목 하나를 정밀 분석하거나, 관심종목 여러 개를 한 번에 스캔해서 매집 점수 순으로 정렬할 수 있습니다.

## 실행

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
# 브라우저에서 http://localhost:8000
```

- 종목코드: `005930`(6자리면 코스피 → 코스닥 순으로 자동 조회), `AAPL`, 또는 `demo`(가상 매집 시나리오)
- 시세: Yahoo Finance 일봉 (10분 캐시)
- CSV 업로드: `Date,Open,High,Low,Close,Volume` 또는 `날짜,시가,고가,저가,종가,거래량` (UTF-8/CP949)

## 탐지 신호

| 신호 | 조건 | 의미 |
|---|---|---|
| 흡수형 매집봉 | 거래량 ≥ 직전 20일 평균의 2.5배, 등락 ±2% 이내 | 쏟아진 매도 물량을 누군가 받아냄 |
| 세력 진입봉 | 거래량 ≥ 3배, 양봉 몸통 ≥ 5%, 고가 근처 마감 | 본격 매수 진입 |
| 아래꼬리 매집 | 거래량 ≥ 1.5배, 아래꼬리 ≥ 봉 길이의 50% | 장중 투매를 받아냄 |
| OBV 상승 다이버전스 | 20일간 주가 ≤ +3%, OBV 순증 ≥ 구간 거래량의 25% | 가격은 눌려 있는데 순매수 거래량은 누적 |
| 거래량 급감(물량 잠김) | 마지막 매집봉 이후 5일 평균 거래량 ≤ 평소의 60%, 주가는 매집봉 저가 위 | 유통 물량 감소 |

## 매집 점수 (0~100)

| 항목 | 배점 |
|---|---|
| 매집성 거래 이벤트(진입봉·흡수봉·아래꼬리) 빈도 | 25 |
| OBV 다이버전스 / OBV 추세 | 20 |
| CMF(20) 자금 유입 | 15 |
| 상승일/하락일 거래량 비 | 15 |
| 급증 후 거래량 급감 | 10 |
| 박스권 수렴(최근 20일 변동폭) | 10 |
| 최대거래일 앵커 VWAP(세력 평단) 위 유지 | 5 |

판정: 70↑ 강한 매집 의심 · 50↑ 매집 가능성 · 30↑ 관찰 필요 · 그 외 특이사항 없음

**추정 매집단가**: 최근 매집 신호일 종가의 거래량가중 평균. 현재가가 이 아래로 크게 내려가면 매집 가설이 약해집니다.

## API

- `GET /api/analyze?ticker=005930&range=1y&lookback=60&spike=2.5`
- `POST /api/upload` (multipart `file`)
- `POST /api/scan` `{"tickers": ["005930", "000660"], "range": "1y"}`
