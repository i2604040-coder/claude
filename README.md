# 세력 매집 탐지기 (Volume Accumulation Tracker)

거래량 패턴으로 세력의 **매집 흔적**을 찾아내는 웹 시스템입니다.
종목 하나를 정밀 분석하거나, 관심종목 여러 개를 한 번에 스캔해서 매집 점수 순으로 정렬할 수 있습니다.

## 실행

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
# 브라우저에서 http://localhost:8000
```

- 종목코드: `005930`(6자리면 코스피 → 코스닥 순으로 자동 조회), `AAPL`, 또는 `demo`(가상 매집 시나리오)
- 시세: Yahoo Finance 일봉 (10분 캐시)
- 수급: 국내 6자리 종목은 네이버 증권에서 외국인·기관·개인 일별 순매수를 함께 가져옵니다 (화면에서 끌 수 있음, 실패해도 분석은 계속)
- CSV 업로드: `Date,Open,High,Low,Close,Volume` 또는 `날짜,시가,고가,저가,종가,거래량` (UTF-8/CP949)

## 탐지 신호

| 신호 | 조건 | 의미 |
|---|---|---|
| 흡수형 매집봉 | 거래량 ≥ 직전 20일 평균의 2.5배, 등락 ±2% 이내 | 쏟아진 매도 물량을 누군가 받아냄 |
| 세력 진입봉 | 거래량 ≥ 3배, 양봉 몸통 ≥ 5%, 고가 근처 마감 | 본격 매수 진입 |
| 아래꼬리 매집 | 거래량 ≥ 1.5배, 아래꼬리 ≥ 봉 길이의 50% | 장중 투매를 받아냄 |
| OBV 상승 다이버전스 | 20일간 주가 ≤ +3%, OBV 순증 ≥ 구간 거래량의 25% | 가격은 눌려 있는데 순매수 거래량은 누적 |
| 기관·외국인 매집 (국내) | 20일간 주가 ≤ +3%, 기관+외국인 순매수 ≥ 같은 기간 거래량의 8% | 주가는 눌려 있는데 기관·외국인이 사 모음 |
| 거래량 급감(물량 잠김) | 마지막 매집봉 이후 5일 평균 거래량 ≤ 평소의 60%, 주가는 매집봉 저가 위 | 유통 물량 감소 |

## 매집 점수 (0~100)

| 항목 | 배점 |
|---|---|
| 매집성 거래 이벤트(진입봉·흡수봉·아래꼬리) 빈도 | 25 |
| OBV 다이버전스 / OBV 추세 | 20 |
| CMF(20) 자금 유입 | 15 |
| 상승일/하락일 거래량 비 | 15 |
| 급증 후 거래량 급감 | 10 |
| 박스권 수렴(최근 20일 변동폭) | 10 |
| 최대거래일 앵커 VWAP(세력 평단) 위 유지 | 5 |

| 기관·외국인 순매수 (국내 종목, 수급 데이터가 있을 때만) | 20 |

수급 항목이 있으면 합계 120점을 100점 만점으로 환산합니다.

판정: 70↑ 강한 매집 의심 · 50↑ 매집 가능성 · 30↑ 관찰 필요 · 그 외 특이사항 없음

**추정 매집단가**: 최근 매집 신호일 종가의 거래량가중 평균. 현재가가 이 아래로 크게 내려가면 매집 가설이 약해집니다.

## 백테스트

**백테스트** 탭에서는 신호와 점수가 과거에 실제로 얼마나 통했는지 확인합니다.

- 신호 백테스트: 신호가 나온 날 종가에 샀다고 보고 5·10·20거래일 뒤 수익률, 승률, 20일 내 최대 낙폭(MAE)을 집계합니다.
- 점수 백테스트: 과거 각 시점(5거래일 간격)까지의 데이터만으로 매집 점수를 다시 계산하고, 점수 구간별 이후 수익률을 집계합니다. 미래 데이터를 쓰지 않는다는 점은 테스트로 검증합니다.
- **기준(baseline)**: 같은 종목·같은 기간에 아무 날이나 샀을 때의 수익률입니다. 신호의 가치는 절대 수익률이 아니라 기준 대비 초과수익으로 판단합니다.
- 여러 종목을 넣으면 표본을 합쳐서 집계합니다. 종목 분석 화면의 **이 종목 백테스트** 버튼으로 바로 실행할 수도 있습니다.

주의: 표본이 수십 건 이하면 우연일 가능성이 크고, 20일 보유 구간이 겹치는 신호는 서로 독립적이지 않습니다. 직접 고른 종목 목록이라 생존 편향도 있을 수 있습니다.

## 대규모 검증 · 가중치 보정

`research/` 폴더에서 300종목(코스피 100 + 코스닥 200) × 5년 데이터로 점수 항목과 신호의 실제 예측력을 검증합니다.

```bash
python -m research.collect      # 시세·수급 수집 (research/.cache, 약 13분)
python -m research.calibrate    # 학습(~2024-09)/검증(2024-10~) 분리 평가, app/signal_evidence.json 갱신
python -m research.calibrate --write   # 검증 통과 시에만 app/weights.json 갱신
```

결과 요약은 [research/REPORT.md](research/REPORT.md)에 있습니다. 핵심:
- 종합 매집 점수의 20일 수익 예측력은 확인되지 않았고, IC 비례로 다시 계산한 배점도 검증 구간을 통과하지 못해 **배점은 바꾸지 않았습니다**.
- 신호별로는 **세력 진입봉**만 두 구간 모두 시장 대비 양(+)의 초과수익(+1.4%, +2.6%)을 보였고, **기관·외국인 매집**은 두 구간 모두 음(−)(−1.1%, −1.2%)이었습니다.
- 화면의 신호 내역과 백테스트 탭에 이 검증 결과가 표시됩니다.

## API

- `GET /api/analyze?ticker=005930&range=1y&lookback=60&spike=2.5`
- `POST /api/upload` (multipart `file`)
- `POST /api/scan` `{"tickers": ["005930", "000660"], "range": "1y"}`
- `GET /api/evidence` (대규모 검증 결과)
- `POST /api/backtest` `{"tickers": ["005930", "000660"], "range": "2y", "flow": true}`
- 모든 분석 API는 `flow`(기본 true)로 국내 수급 반영 여부를 지정합니다
